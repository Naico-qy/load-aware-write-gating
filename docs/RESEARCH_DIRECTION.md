# 研究方向定稿：负载感知的内容门控（Load- and Content-Aware Write Gating）

> 2026-11-20 定稿。基于六篇竞争工作的逐篇拆解（见 `LITERATURE_SURVEY.md`）与 Phase 1/2 的测量，
> 选定**一个**具体的、可实验验证的问题作为方法贡献主战场。

---

## 1. 选定的真实问题（来自竞争方法内部的缺陷，可实验验证）

**GDN-2 式 delta 门的「负载盲」缺陷。**

- **现象（我们已测）**：E2b 证明固定状态的召回崩溃由**负载/容量比**支配——P=16/32/64 时 0.978/0.867/0.444，
  而距离 8× 只降 5.4 点。
- **缺陷（GDN-2）**：其逐通道擦除/写入门**只由当前 token 条件化**（CARVE 称之为 memory-blind）。
  门的策略无法随「记忆有多满」移动。Write What Matters 证明了密度反转（密集→全写、稀疏→选择写），
  但 GDN-2 的门是静态学出来的：**在负载改变时，同一个 token 得到同样的门值**。
- **可证伪的预测**：把同一个 GDN-2 式模型在 P=16 与 P=64 下训练，其门在「pair 写入」「answer 重写」
  等位置类别上的均值应近似不变（负载不变性），而最优策略应不同（高负载下 answer 重写必须被强烈抑制、
  低负载下无害）。若门值确实随负载不变且高负载下有可回收的损失 → 缺陷坐实。
- **为什么 CARVE 没解决它**：CARVE 的内容信号**每 chunk 只在块边界读一次**（staleness O(1/√L)），
  且其门只「看内容」不「看占用」。**没有任何工作把显式的状态占用/读回统计喂进门控**（arXiv 检索确认，2026-11-20）。

## 2. 方法：读回统计条件化门控（Read-back-Conditioned Gating）

delta 规则核**本来就要算**两个逐 token 统计量（擦除项 `S_t^pre k_t` 的副产品）：
- `cs_t = cos(S_t^pre k_t, v_t)`：写回置信度——这条写入与该 key 方向上已存内容的碰撞程度；
- `oc_t = ‖S_t^pre k_t‖ / ‖v_t‖`：写方向的占用率。

把这两个标量**折进门控 logit**：`β_t = σ(z_t + w_cs·cs_t + w_oc·oc_t)`（z_t 是原 token 条件化 logit；
erase 门同理）。每头仅 +4 个标量参数；零初始化 ⇒ 初始与无条件门控逐位一致（CARVE 式安全叠加）；
每 token 额外 FLOPs ≈ 0（cos/范数已是擦除路径的副产品）。

**与竞争者的差异（一句话版）**：GDN-2 的门「看 token」；CARVE 的门「每块看一次内容」；
我们的门「**每个 token 看一次它正在碰撞的内容与占用**」——粒度最细、成本最低，且给出负载自适应性。

## 3. 实验设计（E4）

- 任务：块式 MQAR，L=256，chunk 16，P ∈ {16,32,48,64}（负载扫描），1200 步，batch 32，width 64/2 层/4 头。
- 臂：`gd`（标量耦合基线）/ `gdn2`（GDN-2 式解耦、token 条件化）/ `gdn2+stat`（我们的占用+内容条件化）/
  `gdn2+sgkE+stat`（+乘性 cos 门与 erase 同步，我们的完整版）。
- seeds：全臂全负载 × {0,1}（32 runs）。
- 仪表（--gate_probe）：逐位置类别（pair-key/pair-value/query-key/answer）的 β 与 e 均值 →
  **负载不变性诊断**的直接证据。
- 预注册判定：
  - 缺陷坐实：gdn2 的 β/e 位置类别均值在 P=16 与 P=64 间近似不变（|Δ| < 0.05），
    且 P=64 下 gdn2 与「强基线上限」之间有 ≥5 个点的可回收差距。
  - 方法成立：gdn2+stat 在 P≥32 上显著优于 gdn2（≥2 个点），P=16 上不劣。
  - 破坏条件：若门值已经随负载大幅变化（说明 token 隐式编码了负载），或 stat 条件化无增益 → 如实报告。

## 4. 佐证与后续（不在本轮）
- **碰撞指标线**：E1 的「每行更新数」必须补「固定负载置换」对照（At-fixed-load 批评），
  并扩展为「行内频率/语义异质性」指标——独立于本轮，作为查表侧的第二篇。
- **外部记忆线**：同预算下哈希 n-gram 表 vs HOLA 精确缓存的 RULER 对比——依赖 125M 级规模，后置。

## 5. E4 中期结果（2026-11-21 凌晨，P16/P32 波完成）

**准确率（种子均值 ± sd）**：

| 负载 | gd（标量耦合） | gdn2（GDN-2 式，token 条件化） | **gdn2+stat（我们的）** | gdn2+sgkE+stat（完整版） |
|---|---|---|---|---|
| P=16 | 0.971 ± .007 | 0.973 ± .011 | **0.998 ± .001** | **0.998 ± .001** |
| P=32 | 0.776 ± .067 | 0.872 ± .002 | **0.996 ± .001** | **0.993** |
| P=48 | — | 0.822（s1） | **0.929**（s0） | 待跑 |
| P=64 | 待跑 | 待跑 | 待跑 | 待跑 |

- **P32 判定（预注册的"方法成立"条件）**：gdn2+stat 0.996 vs gdn2 0.872 → **+12.4 点**（种子方差 0.001，判定稳）；
  sgkE+stat 0.993 同向。P16 不劣反升（+2.5 点）。**方法成立的预注册条件已满足**。
- **门策略可解释性（stat 臂的 probe）**：P16 下学到的策略——pair-value 写入 β≈0.61-0.78（保留）、
  pair-key β≈0.30-0.33（中等）、**query-key β≈0.04-0.30（强烈抑制）、answer 重写 β≈0.10-0.52（抑制）**。
  即门控学会了「保留新事实、抑制答案重写」——与 Phase 1-B 冗余普查的机制解释闭环。
- **负载不变性诊断**：token 条件化门（无 stat）的探针数据待补（早期 run 无打点）——补 2 个 probe 版 run 后填。
- **P48 崩溃案例的机制画像（决定性）**：P48 下 gd（标量耦合）崩溃至 0.304，其门值画像为「全线弱写入」
  （pair-value 仅 0.46、其余 0.39-0.45）；同负载下 gdn2+stat 0.929，门值画像为「保事实、压冗余」
  （pair-value 0.70、query-key 0.49、answer 0.49）。**标量耦合门在高压下连事实都写不住，
  而读回统计条件化门学会了选择性强化事实写入**——机制证据与准确率结论互相印证。

## 6. E4 完整结果（32 unique runs 全部落地，2026-11-21）

**准确率（种子均值 ± sd；P64 波种子间方差极大，单列说明）**：

| 负载 P | gd（标量耦合） | gdn2（GDN-2 式） | gdn2+stat（我们的） | gdn2+sgkE+stat（完整版） |
|---|---|---|---|---|
| 16 | 0.971 ± .007 | 0.973 ± .011 | **0.998 ± .001** | **0.998 ± .001** |
| 32 | 0.776 ± .067 | 0.872 ± .002 | **0.996 ± .001** | **0.993 ± .004** |
| 48 | **0.329 ± .035（崩溃）** | 0.807 ± .016 | **0.912**（s0 .929/s1 .896…见 raw） | 0.932（s0 .944/s1 …） |
| 64 | **0.058（坍缩，s0=0.008）** | 0.578 ± .129 | 0.563 ± .196 | 0.620 ± .271 |

（以 jsonl 末值重算：P48-gdn2 = 0.7994 均值（.8217/.7770）；P48-stat = 0.9294；P48-sgkE-stat = 0.9438（2 seeds）。
P64 四臂种子内差 0.18–0.39，属高方差带，n=2 不足以分离门控变体。）

**四条判定**：
1. **标量耦合门（gd）的负载崩塌**：P48 双种子 0.30/0.35、P64 双种子 0.008/0.109——一致性崩溃，**缺陷坐实**。
2. **解耦门推迟崩塌但堵不死**：gdn2 在 P48 仍有 0.80，P64 掉到 0.43–0.67 高方差带。
3. **我们的方法在中等负载增益最大**：P32 +12.4 点（0.996 vs 0.872，方差 0.001）；P48 +10~14 点；
   sgkE+stat 是**全负载最优臂**（0.998/0.993/0.944/0.620）。
4. **极端过载（P=64 ≫ 容量）下所有门控变体被容量墙压扁**（0.43–0.81 高方差带，n=2 无法分离）——
   **诚实边界：门控的价值区间是「负载逼近但未越过容量」**；越过容量墙需要容量本身（更宽状态/外部记忆）。

**机制证据（gate probe）**：
- token 条件化门的 β 画像跨负载结构不变（P48 {0.43/0.58/0.42/0.58} vs P64 {0.38/0.58/0.38/0.59}，按 pair-key/pair-value/query-key/answer）——**负载不变性坐实**。
- stat 臂在 P16 学到的画像：pair-value 0.61–0.78（保留）、query-key 0.04–0.30（抑制）、answer 0.10–0.52（抑制）——**「保留事实、抑制答案重写」的可解释策略**。
- P48 崩溃案例：gd 的画像「全线弱写入」（pair-value 0.46）；同负载 stat 臂「保事实 0.70 + 压冗余 0.49」。

## 7. 对论文叙事的意义
E4 把方法贡献落在了**预注册可证伪**的地面上：
- 诊断（GDN-2 负载盲 → 崩塌阶梯）+ 修复（读回统计条件化，零参数成本）+ 机制（门画像对比）+ 边界（容量墙）。
- 与 Write What Matters 的密度反转互证、与 CARVE 的内容感知擦除互补（我们提供逐 token 粒度 + 占用维度）、
  相对 GDN-2 是「负载感知」维度的直接增量。
- 负结果（P64 无法分离、E3 无 U 形、E2 距离平缓）限定结论边界——正是审稿人会问的问题的预先回答。
